# 麦麦合单官

**改口后重新核价，拿餐时按人核对。**

面向办公室午餐、同学聚餐等多人点餐场景，把群聊里的需求和临时修改整理成合单，再生成逐人分餐看板。

这是一个可安装的 AI Skill，需要配合支持 Skills 和麦当劳官方 MCP 的 AI 客户端使用。AI 负责理解群聊，官方 MCP 提供门店、餐品和报价，本地 Python 脚本校验数量、归属与预算。

## 能做什么

- **整理最新需求：** 区分追加、替换和取消，保留每个人最后确认的餐品与规格。
- **按官方数据核价：** 查询门店菜单、套餐选项和可用优惠券，以官方试算总价检查预算。
- **选择配送与时间：** 支持到店自取、麦乐送，以及门店开放时段内的预约。
- **处理临时修改：** 修改餐品、数量、地址或时间后，旧报价失效，需要重新试算和确认。
- **按人核对分餐：** 生成可离线打开的 HTML 看板，支持筛选、勾选、复制清单和打印。

| 群聊变化 | 处理结果 |
| --- | --- |
| 小王：“我也加一杯美式吧。” | 保留原汉堡，追加一杯咖啡。 |
| 小李：“我的汉堡不要酸黄瓜。” | 根据官方特调选项更新套餐内汉堡；不支持时列为待确认项。 |
| 小陈：“帮我改为两杯美式。” | 小陈改为两杯，其他人的数量不变；旧报价失效。 |

## 查看离线演示

需要 Python 3.10+，无需安装第三方依赖或配置 Token。

1. 在 IDE 中打开并运行 [demo.py](demo.py)，输入、输出路径可在文件末尾修改。
2. 用浏览器打开生成的 `output/demo.html`，查看逐人餐品、报价与预算。
3. 打开 `output/changed.html`，查看修改数量后旧报价失效的效果。
4. 打开 `output/delivery-demo.html` 或 `output/reservation-demo.html`，查看外送费用和预约时间的展示。

也可在项目根目录运行：

```powershell
python demo.py
```

演示使用[示例群聊](examples/chat.txt)、[已整理的计划](examples/plan.demo.json)和[合成报价](examples/quote.demo.json)，不会联网或下单。`demo.py` 展示校验与看板生成，群聊理解由 AI 客户端完成。

## 安装与使用

1. 将 [skills/mcd-group-order](skills/mcd-group-order) 整个目录导入 AI 客户端的 Skills 功能，保留其中的脚本、参考文件和模板。
2. 确保客户端可以运行 Python 3.10+，并按 [MCP 接入说明](MCP_INTEGRATION.md) 配置麦当劳官方 MCP。
3. 提供群聊、配送方式、目标位置或门店，以及预算；预约时说明希望的时间，例如：

> 使用麦麦合单官整理下面的群聊。我们在同一家门店立即到店取餐，总预算 90 元。先让我选门店、核对每个人的餐品和报价，等我明确确认后再创建订单。群聊如下：……

使用流程：整理需求 → 选择配送方式、门店与时间 → 选择餐品并试算 → 查看分餐看板 → 确认完整方案 → 创建订单，由用户自行付款。

外送时先从官方已有地址中选择，再查询可配送门店；仅在用户要求时新增地址。预约时间须从门店返回的可用时段中选择。完整收货信息在 AI 客户端私下核对，看板与复制清单展示配送方式、预约时间和接口返回的费用，不展示收货详情。

看板勾选仅用于人工核对，不会触发下单。无法确定的数量、规格或特调会保留为待确认项。

## 搭配麦麦护栏

合单最后一步是创建订单。如果担心 AI 没等你确认就下单，可以在 AI 客户端和官方 MCP 之间加一层 [麦麦护栏 mcd-guard](https://github.com/a1840436478/mcd-guard)：下单等写操作必须你在本机亲手确认，还能设单笔、当天、本周消费上限。本 Skill 不需要任何改动，只把客户端里的 MCP 地址换成护栏的本机地址即可。

## 使用范围

- 支持单账号、单门店的到店自取或麦乐送，可立即点餐或预约；暂不支持团餐、得来速或多账号拼券。
- 完整套餐归同一个人，暂不拆分套餐子项或计算逐人应付金额。
- 特调必须使用官方接口支持的选项；展示备注不会作为厨房指令提交。
- 修改收货地址、配送方式或预约时间后，需重新查询门店和菜单，再核价、确认。
- 不自动购买会员或付款，不承诺最低价；最终金额以官方订单和支付页面为准。

到店自取的立即与预约流程已完成真实查询和价格试算，31 项离线行为测试通过。外送已完成离线验证，真实外送试算、创建订单、支付和浏览器交互尚未实测，详见 [验证记录](MCP_INTEGRATION.md#当前验证状态)。
